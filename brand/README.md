# Brand files

Not published on the site. Upload these to social accounts:

- `profile-picture-1000.png`: profile picture for Bluesky, X and others (they crop it to a circle)
- `bluesky-banner-3000x1000.png`: Bluesky header banner (also fine for X)
- `logo-512.png`: square logo with rounded corners

The site itself uses `assets/favicon.svg`, `assets/logo-mark.svg`, `assets/og.jpg` and the PNG icons in `assets/`.
`make_logo.py` regenerates everything (needs Playfair Display and IBM Plex Mono .ttf files next to it).
